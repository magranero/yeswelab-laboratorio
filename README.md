# Laboratorio de Yeswelab

Código, entorno y resultados en bruto de los experimentos publicados en [yeswelab.com/experimentos](https://yeswelab.com/experimentos/).

Cada carpeta es un experimento:

- un script para repetirlo;
- `entorno.txt` con el equipo y las versiones exactas;
- `README.md` con cómo ejecutarlo;
- `resultados/` con la salida en bruto: cada cifra del artículo sale de aquí.

Si repites un experimento y obtienes otra cosa, abre un issue: nos interesa.
